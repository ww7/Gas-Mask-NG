# Gas Mask NG 0.8.7-ww7.22

Public prerelease candidate for macOS 13 or later; universal Apple Silicon/Intel.

- Replace permanent system-file write permission with an authenticated, temporary
  root writer. One administrator approval covers the app session; quitting ends
  the helper. Background work never requests authorization and shows Pending
  when applying an update needs approval.
- Harden Remote downloads: HTTPS, bounded same-origin redirects and response size,
  validated UTF-8/hosts data, retained last-good cache and update timestamp.
- Simplify Settings to **Icon** (Mask/Balloon for both menu bar and Dock) and
  **Icon Color Scheme** (all seven approved palettes). Menu bar icons remain
  monochrome templates; changes apply immediately and persist.
- Clarify that Combined diagnostics compare address sets across included files.
  Identical duplicates and IPv4/IPv6 pairs are not conflicts; differences inside
  one source alone are not reported by this cross-file check.
- Present the initial editor after AppKit finishes launching.

Native administrator, cancellation, ACL conversion, authenticated protocol and
crash cleanup checks passed on disposable macOS using synthetic data. See the
repository's BUILD-STATUS and isolated-root acceptance evidence for exact scope.
Physical Intel and sleep/wake/login/uninstall lifecycle acceptance remain open.

No Developer ID signature or Apple notarization. Local ad-hoc hardened-runtime
signatures provide binary integrity/helper identity, not publisher authentication.
No automatic application updater is enabled. Only repository defaults are bundled;
no maintainer profiles or preferences are included. Donations are designated
entirely for Ukraine reconstruction, defense and support for war-affected people.
